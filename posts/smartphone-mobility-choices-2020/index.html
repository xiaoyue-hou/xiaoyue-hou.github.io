2020-Effects of smartphone application usage on mobility choices

智能手机 出行选择 潜在类别模型
Paper
发布日期:   2026-10-28

手机让我们少出门，还是更容易约人一起出门？

论文名片｜Nazmul Arefin Khan、Muhammad Ahsanul Habib、Shaila Jamal，Effects of smartphone application usage on mobility choices，Transportation Research Part A: Policy and Practice，2020，132:932—947。DOI。

同样打开手机，一个人可能把去商店的行程换成网购，另一个人可能因为看到朋友推荐的餐厅而出门。公交实时信息能帮助人少开车，活动信息又可能让人多参加聚会。用手机之后出行增加还是减少，未必有一个适用于所有人的答案。

这篇论文把问题拆成四个维度：访问新地点、计划结伴出行、参加社交聚会，以及车辆行驶公里数。研究的价值在于比较不同用户的回答与生活环境，而证据边界也很明确：结果来自受访者对手机影响的自我判断，不是跟踪同一个人使用应用前后的真实轨迹。

先说结论

  • 手机与移动性的关系会随行为维度改变：更经常社交，并不必然对应更多车辆行驶里程。
  • 模型区分的两类用户对部分变量呈现相反关联。技术熟悉程度可以帮助解释差异，但类别是统计模型推断出来的，不能当作已经测验认证的个人能力。
  • 更偏好可持续出行的人，通常更倾向报告少访问新地点、少计划结伴出行，却增加聚会；车辆里程方向也偏向减少，但不同类别的统计证据并不同样强。
  • 混合用地与应用使用可以共同提供活动机会，但论文没有证明建成环境改变或安装某款应用就会导致特定的出行变化。

386名手机用户，回答的到底是哪一种变化？

数据来自2015年3—4月在加拿大哈利法克斯开展的网络问卷。研究通过现场宣传材料、地方活动、Facebook付费广告和研究团队网络渠道招募，最终有386名智能手机用户。它不是从城市居民中随机抽取的面板，也没有不使用智能手机的人作为对照。

样本中20—34岁者占66.49%，低于25岁占40.7%，学生占68.0%，年收入低于15,000加元者占47.4%。原文认为年龄结构可以合理代表当时的智能手机用户，但没有因此完成对哈利法克斯全部居民的加权代表性验证。学生和全职就业两项可以重叠，不能把两者比例简单相加解释成互斥人口分类。

针对四项行为，受访者分别选择手机应用使用让该行为增加、没有影响，或者减少。车辆行驶公里数（vehicle kilometers traveled，VKT）在这里同样是三分类的自报变化，并不是里程表记录。问卷中的典型工作日、周末出行距离可以作为解释变量，但不等于已观测到应用带来的里程差额。

研究还把住宅位置匹配到2011年人口普查与城市地理数据库，获得人口、住宅密度、住宅结构、土地利用与到市中心、购物中心和公交站的距离。这些是居住环境的关联指标，不能只凭某区自有住房多就确认某个人居住在郊区，更不能把到站距离直接当作实际公交服务质量。

表2｜哪些人进入样本，模型用什么解释他们的回答？

左列为变量，第二列给出定义，右侧为均值或比例及标准差。样本中汽车通勤占39.3%、公交通勤占28.5%；高度依赖应用规划出行者占22.1%。建成环境和可达性变量来自住宅所在地区与空间匹配；表中距离单位为公里。来源：原论文 Table 2。

所谓支持可持续出行，具体如何测量？

问卷用同意、中立、不同意三档询问态度。面对多项高度相关的问题，论文采用主成分分析（principal component analysis，PCA），并进行 varimax 旋转，压缩成信息通信技术态度与可持续出行态度两个分量，报告合计解释88%的样本方差。

表1实际展示四项陈述的载荷。技术态度主要与容易适应新技术、智能手机改善日常生活相关；另一分量与重视商店服务的邻近性、认为出行时间通常是浪费相关。这意味着可持续出行态度是作者对这一组相关回答的命名，不能直接替换成每个人实际步行、骑行或乘公交的比例。

表1｜态度标签背后是哪几道问卷题？

行是四项陈述，列是两个分量的载荷，绝对值较大表示该题与相应分量联系较强。两列报告解释方差33%与55%。载荷不是某种干预的效果，也不是增加一次应用使用就会改变多少出行。来源：原论文 Table 1。

为什么不直接给所有人拟合一个平均关系？

如果两类人在应用使用后有相反变化，汇总平均可能掩盖这种差异。论文因此建立四个潜在类别随机参数 Logit 模型（latent class random parameter logit，LCRPL），每种行为一个模型。它先按年龄、收入、手机使用年限和住宅环境等变量，给每个人属于不同类别的概率；再在类别内部估计对增加、不变、减少三种回答的倾向，并允许部分参数按正态分布变化。

这里有两层差异：类别之间的平均关系可以不同，同一类别内部的人也可以不同。模型使用200次 Halton 抽样近似积分；抽样是计算过程，不是再调查200批人。类别归属具有概率，不能把一名受访者永远固定为某个类型。

作者根据各模型的类别分配特征，把两类称作技术熟悉型与技术不熟悉型。比如使用智能手机超过五年、年龄较轻等特征通常更接近前者；这是事后解释，并非独立测试出的数字技能等级。四个模型分别估计类别，技术熟悉型的报告分配概率依次为访问新地点30%、结伴出行69%、社交聚会79%、VKT 59%。同一个名称下比例相差很大，不能把它们理解为一套统一人口标签，也不能把类别比例当作行为增加的比例。

表3｜为什么正文最后报告两类模型？

四组列对应四项行为，每组比较两类与三类模型。按表内报告的AIC、BIC，两类均较小；这些数值以原表尺度报告，不能当作预测准确率。三类拟合的对数似然反而更差，提醒我们这里比较的是作者获得的拟合解，不能据此证明世界上只有两类用户，或已经排除局部最优与其他模型设定。来源：原论文 Table 3。

读后面四张结果表时，还有一个容易误会的地方：系数是选择模型中的参数，不是公里数、百分点或百分比。完整概率由所有选项、类别权重和随机参数共同决定，不能把一个系数直接写成变化了多少出行。表中一、二、三个星号分别对应10%、5%、1%的显著性水平；没有星号的方向只能作为较弱线索。原文保留了一些低于90%置信水平的变量，其未来样本扩大后是否显著，并未得到证明。

新地点与结伴出行，为什么可能朝不同方向变化？

访问新地点模型中，两类用户对技术的积极态度都与更倾向回答增加相关；汽车通勤、家庭车辆更多和周末出行距离更长，也通常朝同一方向。这支持一种有条件的解释：手机提供信息，已有交通资源提供抵达能力。但研究没有直接追踪哪一条餐厅推荐触发了一次旅行。

与此同时，可持续出行态度在两类的增加选项中分别为−0.034与−0.013，前者有5%水平证据，后者为10%水平。减少选项中的关联方向相反，但第二类的正系数没有星号，不能说两类所有方向都同样稳健。公共交通通勤者的差别也很明显：技术熟悉型更倾向回答增加访问新地点，而另一类更倾向回答没有影响。

表4｜同样使用应用，谁更倾向报告探索新地点？

上半部分为类别分配，下半部分按增加、没有影响、减少列出两类参数，最下方列出部分随机参数的标准差。技术熟悉型与另一类的样本分配概率为0.30与0.70；它们不是探索行为增加的概率。公交、态度与土地利用部分存在类别差别，需连同星号判断证据。来源：原论文 Table 4。

结伴出行模型则说明，依赖手机规划并不对所有人具有相同含义。高度依赖应用者在技术熟悉型的增加选项系数为6.122，在另一类为−1.717，两者均有5%水平证据；后者的没有影响选项为正。这是类别之间的关联差异，不应把6.122理解成多出六次行程。

汽车通勤在两类的增加选项中都为负；公交在技术熟悉型中为正，在另一类中为负。一个可行解释是，不同用户使用的工具和出行组织方式不同，但问卷没有把导航、社交网络、拼车等具体应用的使用剂量与相应行程逐次配对。正向可持续出行态度与较少报告增加结伴出行相关，也不能据此断言环境意识削弱社交关系。

表5｜谁更容易把应用转化为结伴出行？

三组选项列中，各有两类用户参数。高度依赖应用与公交通勤在增加选项上呈类别反向关联；随机参数区显示类别内部仍有差异。住宅自有比例在技术熟悉型的没有影响选项中，均值0.015、标准差0.697，提示平均正号不能代表每个人都同向，但也不能脱离正态分布假设推算真实个体比例。来源：原论文 Table 5。

少探索新地点，为什么仍可能参加更多聚会？

去没去过的地方与见不见朋友，是不同的活动维度。社交聚会模型中，高度依赖应用规划与两类用户更倾向回答增加相关，增加选项参数分别为0.579与6.055，证据强度分别达到1%与10%水平。可持续出行态度在增加选项中也都为正，分别为2.199与1.279，对应10%与5%水平。

这与访问新地点的方向不同，并不矛盾：聚会可以在熟悉的社区、朋友家或经常到访的地方举行。论文借助可持续交通促进联系的既有文献解释这一点，但当前数据没有把这种机制直接测出来。支持可持续出行的人更愿意聚会，也可能与生活方式、社区选择和问卷表达方式共同有关。

混合用地在两类的增加聚会选项中都为正，但均只有10%水平证据。附近有多种活动设施，可能使手机信息更容易转成线下见面；它不证明把土地用途混合后就必然增加聚会，也没有排除本来更喜欢社交的人选择此类住宅环境。

表6｜手机与线下聚会之间的关系是否因人而异？

上方为类别分配；参数区分别对应三种自报变化。可持续出行态度、应用依赖和土地利用的方向可以与另外三个行为维度比较，但不同模型系数不能直接按绝对大小排列效果强弱。随机参数区还显示，周末距离及应用依赖的关联在类别内部也有变化。来源：原论文 Table 6。

多社交是否一定意味着多开车？

VKT模型给出另一组有区别的关系。高度依赖应用规划的技术熟悉型，更倾向回答车辆里程增加；另一类则更偏向减少。混合用地对增加VKT选项的系数也反向：技术熟悉型为−5.828，仅达到10%水平；另一类为1.827，达到5%水平。相同的城市环境与不同的数字工具使用方式，可能同时出现在不同出行组合里。

原文把技术熟悉型汽车通勤者倾向减少VKT，解释为可能更多使用拼车或共享汽车。不过，汽车通勤者在该类减少选项的系数0.894具有5%水平证据，而增加选项的负值−4.258没有星号。我们可以报告较强的减少关联，不能把所有相关系数都写成已证实变化，更不能确认拼车就是原因。

可持续出行态度在技术熟悉型中与较少报告增加VKT、较多报告减少VKT有1%水平证据；另一类对应系数方向相近，但没有星号。因此，结论应保留两类证据强度差别。研究也没有测量各类变化的实际公里数，无法把更多聚会与更少VKT合成总体碳减排量。

表7｜应用使用与车辆里程的关联，为什么有时会反向？

三组选项仍是受访者报告增加、没有影响、减少，而非真实里程计数。应用依赖、汽车通勤和混合用地均呈现类别差异；底部标准差属于假设的随机参数分布。由此可以提出差异化服务假设，不能直接预测换一款应用能减少多少公里。来源：原论文 Table 7。

这些结果可以支持怎样的政策判断？

论文主张让公交信息、活动机会和社区空间相互配合，而不是假定所有手机用户都能从同一种工具获益。对熟悉应用的公交通勤者，出行信息与社交活动可能相互补充；对另一类用户，界面、信息渠道或既有习惯可能让相同工具难以带来变化。混合用地与活动设施也需要真正可达的交通服务，才能把信息机会变成线下活动。

这些是可供进一步验证的设计方向。当前研究的限制包括便利招募、单城小样本、2015年的应用生态、自报归因以及较多参数与多重比较；缺少随机干预或应用使用前后的面板，态度、住宅选择、出行习惯之间的内生关联仍然存在。模型同时使用关于手机社交影响的回答解释其他自报影响，还可能受到共同测量方式影响。

因此，远程办公必然减少净里程、拼车实际增加或数字技能直接改变排放，都超出了当前数据的直接证据。论文对这些机制提出解释与政策建议，不等于已经验证干预效果。

一句话总结

手机应用可能重组人们去哪里、和谁见面、怎样出行，但这份问卷最有力的提醒是关注用户与行为维度的差别，而不能把自报变化当作已测得的因果减排。

延伸思考

以下是 AI 基于论文结果所作的延伸，不属于原论文结论。

判断一款出行应用有没有帮助，不妨同时测量三件事：参与者是否更容易完成想做的活动、交通方式怎样改变，以及实际车辆公里数怎样变化。若一个人多参加了附近聚会、增加步行却减少开车，活动数量上升与环境负担下降完全可以同时发生；只看总出行次数会错过这种组合。

更有辨识力的研究可以把新功能分批开放，在授权条件下记录功能使用和出行日记，并保留未开放功能的比较组。与此同时，用独立任务测量数字工具熟悉程度，而不是只依据年龄和手机年限命名类别。这样才能区分应用提供的帮助、个人原有能力和生活环境各自起了什么作用。

还可以特别观察原本不容易使用工具的人：如果简化界面、保留线下信息和改善站点服务能改变他们的出行，问题就不只是开发更多功能。数字服务的可用性与现实交通的可用性，需要在同一个评估框架中检验。
