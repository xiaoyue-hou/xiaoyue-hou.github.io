居住迁移 搬家 家与地方 生命历程
Paper
发布日期:   2026-11-11

人搬走了，家还留在原来那栋房子里吗？

论文名片｜Caitlin Buckle，Residential mobility and moving home，Geography Compass，2017，11：e12314。DOI：10.1111/gec3.12314。收稿日期 2016 年 12 月 2 日，修回 2017 年 3 月 23 日，接受 2017 年 3 月 27 日。这是一篇概念与方法综述，不是新的搬家抽样。

同一条街上，一个人搬进更大的房子，另一个人离开一间不能再待的房子。两份登记都只是把常住地址改了一行。旁人很容易用同一句话概括这两次搬家：不稳定。地址改了，家是否还停在原来那栋房子里，表格本身不回答。

Buckle 把居住迁移（residential mobility）写成日常活动连同通常居住地一起换到另一处。宽定义可以包含国际迁移；地理学里它通常指较短距离的搬家，例如区域之间、城市内部或一国之内的迁移。旅行、因工作而作的短期停留、度假和临时流动，不在这个定义的中心。住房研究又常常把搬家收成住房生涯（housing career）：按产权、住房条件和区位去满足变化中的需要。家作为可以居住、可以感到安全的生活经验，就留在定义外面。

这篇综述的方向性判断是：家不一定钉在一栋不动的房子上。搬家可以打乱家，也可以被人用来离开限制、不适或伤害，并在下一处把家重新做成。只记录一个静止常住地的普查和调查，能描述宏观趋势，读不出这两种经验的差别。全文没有新样本、新地图或新的迁移率，下面每一条都是她对既有文献的重新组织，以及她认为下一步方法应该补上的缺口。

先说结论

  • 居住迁移在这里是通常居住地的变更。它被用来和旅行、短期工作停留、度假、临时流动区分；住房生涯能描述房子和区位怎么调，却还没有说明家的生活有没有一起搬走。
  • 定居主义把长期住在一处当成正常，把经常搬家的人看成与家脱节。综述并列了两套既有叙事：一套把搬家与分离、不满、市场波动和青少年问题连在一起，另一套把搬家写成生命阶段里调整住房和邻里的办法。本文没有给出哪一套更常见的比例。
  • 新流动范式把地方看成过程或体验，把家看成可以在下一处重建的生活。对有的人，空间上的独立搬到隔壁就够；对另一些人，要跨州才发生。这里没有统一的公里阈值。
  • 单一常住地的普查适合描述所谓典型搬家和宏观结构，却难容纳活动住房、同时拥有多处住所，以及按季节在两地轮流安家。居住传记、民族志和叙事研究被用来看见这些被省掉的轨迹。
  • 生命历程框架同时看个人阶段、相连的生活、时间、地方和文化。这一领域的纵向研究仍以定量为主，个人怎样感受家仍然说不透；定性叙述又容易错过更广的权力关系。把两类方法放进同一框架，是作者提出的研究方向，不是已经完成的检验。

常住地换了，家的生活有没有一起换？

Bell 与 Ward（2000）以及 Rossi（1955）给居住迁移的基本口径：搬的是通常居住地，也就是日常活动所在的那一处。Coulter 与 van Ham（2013，第 1037 页）在生命历程里把它定义成一种机制，让家庭能够调整住房、邻里和区位消费，以配合变化的需要和偏好。Clark 与 Dieleman（1996）、Clark 与 Huang（2003）、Mulder 与 Hooimeijer（1999）则把这种调整放进住房生涯，讨论的是产权和住房市场中的选择，不是屋子里的生活是否还像家。

漏掉家，有可以理解的原因。Relph（1976）代表的一条传统把流动看成对家庭生活的打扰；Blunt 与 Dowling（2006）则指出，家在实践中的含义本来就难定。Buckle 的主张是，若把居住迁移理解成家的生活被搬到另一处，它和短时间、即使距离不一定远的其他移动就分得更开。矛盾也因此出现：搬家在文献里被写成家的破坏，也被写成家的改善，而测量常常只抓住房子。

长期住在一处，为什么被当成正常？

定居主义（sedentarism）把定居文化当成规范，把居住上经常移动的人看成例外，并假定他们与家的联系更弱。Cresswell（2006）和 Relph（1976）是这条批评所针对的思想来源。几组已被边缘化的流动生活说明，固定地址并不只是个人习惯，也是一套制度和财产秩序。

罗姆人没有固定地址，常被当成越轨甚至犯罪的标志；不愿或不能符合定居规范，在欧洲和美洲的所在国引出种族主义。Holloway（2003，2005）和 Kabachnik（2010）被引用在这里。栅栏、国境以及财产法会切开原本的移动路径（Kabachnik，2012；Kabachnik 与 Ryder，2013）。在澳大利亚，英国殖民者没有承认原住民在地方中居住的方式。人口稀疏、流动实践和居所相对短暂，被用来支持无主之地（terra nullius）的主张（Banner，2005；Prout，2009）。西方以房屋产权排列的家，盖过了原住民对家园（homeland）的经验；仍在一组地方之间流动、不按定居规范生活的人，继续被当成问题（Behrendt，1999；Taylor 与 Bell，1996）。这些是综述引用的历史和地理文献，不是 Buckle 在本文里做的田野。

综述接着写，就居住迁移而言，全球多数人是不动的，所以住房、产权、就业、学校和其他服务基础设施主要按住在一处来设计（de Jong，2000；Prout，2008；Wolf 与 Longino，2005）。这句话没有附带人数、国家名单或百分比。后文把长期留在一处的安适写成特权：人可以留在原地，同时并没有这种安适。

同样一次搬家，文献把它连向破坏，也连向改善

当家被放进居住迁移和游动生活时，常见描述是不安、不稳（Brednikova 与 Tkach，2010）。Relph 的两句话需要同时保留。他承认，最常移动、最不稳定的人并不自动就是无家可归或没有地方的人（1976，第 30 页）；他又认为，西方社会居住迁移的增加，既依赖也加强了家的重要性下降（1976，第 83 页）。前一句阻止把搬家者直接写成失去家，后一句仍然把更多搬家和家的意义变弱绑在一起。

综述把一批负面叙事列在健康、住房、犯罪学和社会学里：搬家曾被与伴侣分离（de Jong 与 Graefe，2008）、家庭破裂（Feijten，2005）、住房市场下行和不稳定（Ferreira、Gyourko 与 Tracy，2010；Kull、Coley 与 Lynch，2016）、个人不满（Nowok、van Ham、Findlay 与 Gayle，2013）、青少年违法和药物使用（Porter 与 Vogel，2014；Stabler、Gurka 与 Lander，2015）连在一起。Buckle 的用词是被关联、这些叙事暗示搬家与家所代表的稳定和安全相反。她没有重算这些研究的样本，也没有裁判其中哪些是因果、哪些是选择。Porter 与 Vogel 的题目本身就在追问因果还是选择，本文没有展开这个裁决。

另一批文献把搬家写成生活可以变好的途径。它可以用来改善住房或邻里（Clark 与 Onaka，1983；Clark，2009；Clark、van Ham 与 Coulter，2014）。Rossi 的《Why Families Move》（1955）把搬家看成家庭境况变化时的自然考量，而且这本书早于 Relph。综述点出的生命阶段包括：年轻人离家，寻求独立并走向自有住房（Holdsworth，2013；Ronald，2008）；预期要孩子时离开城区、寻找更适合家庭的地方（Kulu，2008；Michielin 与 Mulder，2008）；退休后迁往环境条件更好的地方（Stockdale，2006，2014）。搬家也可以成为结成亲密关系和扩大社会网络的资源（Holdsworth，2013）。这些仍然是被引用研究的关联和解释，不是本文新测到的阶段转换率。

固定待在一处的安适，被写成特权。单一地点可以是家务役使、恐惧或虐待发生的地方，离开那里，才可能找到在家的安全（Blunt 与 Dowling，2006；Jones，2000；Massey，1994）。Cairns（2008，第 243 页）的说法是，搬迁可以把人从原住地的限制里解放出来。新自由主义政策则鼓励个人用搬家争取向上的社会流动（Imbroscio，2012；Sharkey，2012；Clark 等，2014）。综述对此保持张力：这种鼓励引出一个规范问题，流动究竟该被促成、允许，还是加以防止。人可以靠搬家离开原处的问题，流动的结果却可能是社会空间上的劣势更集中，改善生活的责任被放到个人身上。能搬走以改善处境的人，和由于各种原因搬不走的人，并不站在同一位置。

自愿和被迫也不容易切开（Imbroscio，2012）。被迫搬家可以极度扰乱、令人痛苦；想搬而搬不成，也会影响生活质量（Coulter 与 van Ham，2013）。因此，住房变好或地址变了，都还不能代替这个人怎样经历这次搬家。地理学者被引向搬与留所暴露的权力结构（Coulter 与 van Ham，2013；Coulter、van Ham 与 Findlay，2016）。这一步仍是问题的重新摆放，不是一组已经估计好的因果效应。

地方若是一种体验，家怎样搬到下一处？

新流动范式（new mobilities paradigm）从 1990 年代起反对把地方看成静止容器、把流动看成对地方意义的破坏（Hannam、Sheller 与 Urry，2006；Massey，1994；Sheller 与 Urry，2006）。Urry（2000）把地方看成由跨越时间和空间的网络与联系构成，而不是戏剧布景。地方在这一传统里被说成过程（Massey，1994；Pred，1984）或体验（Cresswell，2009）。人在移动中与周围环境互动、赋予意义，因而与地方相连（Adey，2006）。Cresswell（2011，第 551 页）把流动放回日常生活的微观地理，它不再只是边缘的、破坏性的或一次性交易。

旧的居住迁移图像更接近经济机会主义者：人随住房市场和劳动力市场起伏而搬，对地方本身缺少牵挂（Dieleman，2001；Ravenstein，1885，1889；Wolpert，1966；Zelinsky，1971）。放进新流动范式之后，搬家可以是经验地方的一部分，而不是与地方断开（Coulter 等，2016）。摘要把家的一种更动态、更包容的理解归于 Gillespie（2017）：家是可以逐地搬走的生活经验。正文随后用地理学者自己的概念把这个说法展开。

Holdsworth（2013，第 45 页）提出空间独立（spatial independence）。人搬家，是为了在父母监视之外做成另一种身份、新的社会网络和伴侣关系。这种需要受社会、地理条件和文化预期影响。对有的人，搬到隔壁就够；对另一些人，可能要跨州。隔壁和跨州是两种生活尺度的对照，论文没有给出公里数。人在地点之间搬动，也参与了地方如何形成、地方之间如何变得不同。Kloep 等人（2003，第 104 页）的说法被用来指向：搬家是在考虑去哪里能接触更合意的环境，从而探问自己在世界中的位置。综述同时写明，这并不总是正面经验。

家的概念跟着改变。一种熟悉形象把家说成外面纷乱移动之外的安宁，一栋静止的房子似乎就够了（Heidegger，1996）。Blunt 与 Dowling（2006）以及 Cresswell（2006）指出，把这一栋静止的房子当成家，带有定居主义，也带有男性中心的视角。Young（2005）认为，家作为物质住宅被这样理解，本身有性别维度；做成家，并不只是造一栋固定的房子。de Certeau、Giard 与 Mayol（1998）被用来说明，家也由屋内和周围的日常实践做成。家可以是安宁的经验，却不必然要求身体停在原地。

Blunt 与 Dowling（2006，第 5 页）把家写成安全、个体化、隐私和保存得以发生的地方。这个理解不依赖某一栋建筑，也因此可以在不同地点被重新做成。综述认为，几项当下趋势使这个定义更需要被认真对待：跨国生活（Blunt 与 Dowling，2006）；自有住房下降、人们更依赖不稳定的私人租赁（Burke、Stone 与 Ralston，2014；Lund，2013）；家庭、工作和社交网络可以借助虚拟技术维持（Knies，2013）。下降了多少、租赁不稳定如何计量，本文都没有给出数字。Ralph 与 Staeheli（2011，第 525 页）的概括被整句引来：家在地理学讨论中可以同时是流动的和定居的，既固定在当地，又可以向远处延伸。

家的可移动性直接挑战另一种直觉：一搬家，家的经验就丢失了。换常住地可以是摆脱日常限制，也可以是在另一处把家做得更好。Fortier（2001）和 Gorman-Murray（2007）写到，许多酷儿把那一处童年住宅看成身份被压抑的地方；对他们而言，回家是搬向对酷儿更友善、常常是城市的环境。Gorman-Murray（2007，第 109 页）写，身体的移动和身份的改变可以在同一次搬迁里一起完成。Altman 与 Low（1992）把在不同地点重新做成家的能力称为自我的可移动性（mobility of self），并在跨国迁移者那里讨论它。综述的推论是：把流动一律看成与家断开，是把流动者的生活经验简化了。家和地方怎样随居住迁移变化，应当被探究，而不能事先假定。这些例子各自来自被引用的研究，不能合并成一种搬家者的典型心理。

一个常住地址，会漏掉哪些居住方式？

居住迁移研究大量使用普查和调查。这些指标通常假定家是单一且静止的地点（Coulter 等，2016；McHugh 与 Mings，1996；Prout，2008）。它们为的是认识所谓典型的搬家者，并揭示较大尺度的结构、权力关系和趋势。规划者和决策者仍然需要这种描述。限制出现在下一步：多样的人、多次方向不同的搬家，很难被这套指标保住。

固定地址加上定量分类，容易把人放进舒适型、经济型、逆城市化、国际迁移或国内迁移等类别（Geist 与 McManus，2008；King 与 Skeldon，2010；Stockdale，2014）。类别概括的是一次或生命中少数几次移动，并倾向于把迁移当成单向旅程（McHugh，2000，第 71 页）或单一事件。普查也难记录在非永久或半永久建筑之间移动的人、住活动房屋或房车的人，以及同时拥有多处住所的人（Behr 与 Gober，1982）。住处可以不是一栋房屋。

更进一步的问题是规范判断。新自由主义逻辑把居住迁移说成个人改善处境的权利；定居主义意见则认为流动有损于地方和家的形成。许多研究盯住住房或经济上的舒适，较少讨论社会网络、经验和家庭生活。这种焦点等于假定：房子更好，或搬到社会经济上更合意的地点，家就改善了（Clark，2009）。综述认为实际情形可以两边都发生。同一次搬家既能让家变得不稳，也能改善家的生活；如何并存，取决于住房和社会经济地位以外的许多条件。家是主观的，它和流动的关系取决于个人处境和生活经验。

1990 年代到 2000 年代，更多研究改用定性材料看这种经验：家的地点可以构成网络，家可以有多重，家本身也可以是移动的（Gustafson，2001；McHugh、Hogan 与 Happel，1995；McHugh 与 Mings，1991；Silvey 与 Lawson，1999）。Kabachnik（2010）用民族志讨论罗姆人如何在社区一起移动时把家做成；他强调，换地点之后仍能安家，依赖的是一起搬走的社会网络保持稳定。Mason（2004）用叙事说明相连的生活（linked lives）如何进入个人的居住决定，而这在传统居住迁移方法里常常抓不住。Gutting（1996）深度访谈的是一对已经搬到德国的伴侣。叙述分析显示，他们既想回到原居地，又因家庭和已经建成的生活而想留下。这里的规模就是这一对伴侣，不是一项报告了抽样误差的调查。

要看见家的复杂变化，也可以把搬家放在时间里看。纵向材料（de Jong，2000；Rossi，1955）和传记方法（Clark，2009；Coulter 与 van Ham，2013；Halfacree 与 Boyle，1993；Skeldon，1995）被用来讨论一个人一生中的多次搬迁（Findlay 与 Wahba，2013）。Findlay 与 Li（1997）说明自传式材料可以考察过去的经验如何影响以后的居住迁移，并讨论回迁、循环和季节性迁移；宽口径的人口调查常常忽略这些（McHugh 与 Mings，1996；Stockdale，2014）。McHugh 与 Mings（1996）为亚利桑那的候鸟式居住者整理传记：家按季节、轮流在两个地方做成。Clark（2009）则用多份迁移传记呈现所谓贫困邻里里的经验怎样是个人的、关系性的、主观的。这些方法的共同作用，是让一次地址变更展开为一段居住史。

生命历程能同时放下人和结构，家的感受仍在外面

生命历程（life course）从 1990 年代起被用来替代较固定的生命周期（life cycle）（Clark 与 Dieleman，1996；Mulder 与 Hooimeijer，1999）。Skeldon（2012）点出的困难是：个人因素，以及更广的结构和社会因素，会在时间里同时影响搬家。生命历程框架被看成回应新流动范式的一种办法，因为它既看个人的能动性和生命阶段，也看搬家发生时的相连生活、时间、地方和文化（Bailey，2009；Coulter 与 Scott，2015；Elder，1994；Kulu 与 Milewski，2007）。

身份和位置如何影响搬家，可以在这个框架里被追问（Coulter 等，2016；Feijten、Hooimeijer 与 Mulder，2008）。Kley（2011）的调查包含社会人口变量、心理特征、社会纽带、对机会差别的感知，以及预期中的生命历程事件。综述说，她找出了促使人很可能迁出德国马格德堡和弗赖堡的因素组合。组合里哪一项更大、样本有多少人，本文没有列出。

按这篇综述的说法，Falkingham、Sage、Stone 与 Vlachantoni（2016）比较了英国三个出生队列在 1950 年以前的居住迁移。他们用纵向方法和生命历程框架，把子女、就业、伴侣关系等事件放进社会与历史情境，考察一生的居住迁移轨迹。综述从中取出的发现是轨迹变化的性别化：社会历史情境对男性和女性生命历程事件的影响并不相同。三个队列没有配套的人数，因此这里不能算出任何一个迁移率。

Coulter 与 van Ham（2013）被单独提出，是因为他们让流动和不动彼此对照。顺着个人的居住迁移传记看下去，实际搬了家和想搬家有时并不重合。留在原地可以是愿意留下，也可以是想走而没有走成。这一区别直接关系到前面的规范问题：不能把所有地址没变的人都读成家是稳定的。

尽管路径已经很多，Buckle 仍认为它们各自只抓住家的动态经验的一部分。定量普查和调查能建立背景、写成流动与迁移的宏观叙述，却不增加关于家的个人经验的内容。居住迁移领域的纵向和生命历程研究大多仍是定量的；只靠这些测量，个人对家的经验和理解很可能仍然说不清楚。这句话是对研究分野的判断，不是一篇统计了定量论文占比的元分析。

定性的传记、叙事和民族志让参与者讲出家的个人经验，却可能错过经验身处其中的更广权力关系。综述看到的机会，是在生命历程框架里同时使用两边的长处。定量描述这些搬家、揭示流动与不动中的权力不平衡，并给出政策和决策需要的结构影响；定性则提供关于搬家和家的规范视角。结构、环境和文化怎样作用在一个人一生对家的经验上，需要两种做法一起看。生命历程框架在地理学中的使用，以及框架内可以更换的方法，被她看成试验新做法的条件。这是建议，不是一套已经跑完的混合设计，也没有相应的结果表。

这些判断停在什么地方？

这篇综述能支持的是概念重组和方法议程。家是居住迁移的核心概念，而搬家者多样、个人化的家的经验仍常被漏掉。把搬家写成与家、与地方无关，会进一步把流动中的人推到边缘，而不是去看究竟是哪些权力关系和个人因素让人搬家。新流动范式把地方与流动连在一起，居住迁移文献因而要同时看一段时间内作用于流动的权力，以及搬家带给家的困难、好处和经验。纵向、民族志、叙事、传记和生命历程方法已经用来探索影响流动的复杂因素，也可以继续用来看一生中搬家的经验。接触这些关于家与地方的概念，有可能帮助地理学者处理一个长期含混的问题：流动和不动在何时、何地、因为什么值得追求。本文只把这写成一种可能，并没有回答这个问题。

不能从本文推出的内容同样明确。这里没有原始样本、对照、地图或效应值。负面叙事和生命阶段关联都属于被引用研究，分母没有被搬进这篇综述。全球多数人在居住上不动，是一句没有百分比的判断。自有住房下降和私人租赁不稳定也没有计量。自愿与被迫没有操作定义。罗姆社区、澳大利亚原住民的家园、酷儿的城市搬迁、德国两座城市、英国三个队列、亚利桑那的季节性两地居住、一对迁德伴侣，分别说明不同论点，不是同一总体。定居规范主要在西方社会和西方产权等级下被讨论，文外的推广需要另找证据。作者自己的海岸迁移研究出现在文末介绍里，不是这篇综述的结果。

一句话总结

人搬走以后，家不一定留在原来那栋房子里，也不一定在新地址上自动变好；只改一行常住地址，看不出家的生活是被打断、被带走，还是根本没有随这次搬家发生。

延伸思考

以下是 AI 基于论文结果所作的延伸，不属于原论文结论。

如果公共服务仍只接受一个通常居住地，季节性的两地生活会在表格上消失。综述转述的亚利桑那候鸟式居住，是家按季节轮流在两个地方做成。学校学籍、社区医疗或邻里资格若必须绑定唯一地址，就会把其中一处记成家，把另一处记成临时外出。下一步值得问的是：当同一个人说自己在两处都安家时，哪些服务规则只承认表格上的那一个地址，哪些生活实践因此被记成不稳定。

另一处容易误读的是搬成了才算改善。综述已经把三件不同的事放在一起：被迫离开会扰乱生活，想搬而搬不成也会影响生活质量，能搬走的人和搬不走的人并不对称。若一项评估把已经搬家的住户数除以全部住户，当作居住改善的成功率，被迫搬走和自己选择搬走会进同一个分子，想走却留下的人会因为地址没变而留在分母里，看起来像稳定。至少先分开三种处境，想留下、想搬但搬不成、已经搬成，再问家的安全感和日常安排分别落在哪一种里。这篇综述没有做这个三分，也没有报告相应人数。
